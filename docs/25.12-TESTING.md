# WR30U 25.12 迁移测试清单

本清单适用于 `25.12-test` 分支产生的 Prerelease。它不是刷机教程；在恢复路径不明确时应停止测试。

## 刷写前

- 确认设备确实使用 OpenWrt U-Boot Mod，而不是原厂或 MTK U-Boot 布局。
- 确认可进入 U-Boot 恢复界面，并准备有线电脑、已验证的 24.10 回退固件和独立配置备份。
- 校验下载文件与 Release 中 `sha256sums` 一致。
- 核对固件名包含 WR30U、ubootmod 和 `sysupgrade.itb`。
- 第一次跨大版本测试不保留配置；不要导入包含软件包状态的完整 24.10 备份。
- 记录当前接口、VLAN、无线和必要的 HomeProxy 规则，但不要记录订阅、节点或设备身份等敏感内容到公开仓库。

## 首次启动基线

1. 只连接一台有线测试设备，确认冷启动和 `192.168.2.1` 管理地址。
2. 设置管理员密码，确认 LAN、WAN、DHCP、IPv4 和按需使用的 IPv6。
3. 保持 HomeProxy、TurboACC/HNAT 和其他附加服务关闭，完成一次重启和断电冷启动。
4. 使用 `drill` 分别测试路由器、运营商 DNS 和可信公共 DNS，记录首包延迟、失败率和重复查询表现。
5. 使用 `iperf3` 检查有线及 2.4/5 GHz 局域网吞吐；检查无线重连和漫游。

## HomeProxy 与新增连接测试

1. 先启用 HomeProxy，但保持 TurboACC/HNAT 关闭。
2. 使用最小规则验证 DNS、直连、代理和路由器自身流量，确保代理服务器地址不会再次进入透明代理。
3. 连续创建多台设备的新连接，观察是否出现“已有连接可用、新连接全部失败”。
4. 出现异常时立即记录匿名化的时间点、`nf_conntrack_count`、`nf_conntrack_max`、内存、dnsmasq/HomeProxy 日志摘要和规则命中情况。
5. HomeProxy 基线稳定后，才单独启用加速进行 A/B 测试；一旦复现异常，关闭加速并再次验证。

## 通过条件

- 至少三次冷启动和一次断电恢复正常。
- DNS 连续测试无明显超时或间歇性失败。
- HomeProxy 开启时，多设备新增连接不被阻断。
- conntrack 数量不会持续逼近上限且内存无持续泄漏。
- 有线、无线及日常业务连续运行 48～72 小时无阻断性故障。
- 能按预先准备的路径恢复到已验证的 24.10 固件。

未全部满足时，25.12 继续保留为 Prerelease 测试分支。
